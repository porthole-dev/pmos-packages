# Contributing

This repository only holds build output. Packages are changed in
[porthole-dev/pmaports](https://github.com/porthole-dev/pmaports), whose CI
builds and publishes them here; see its
[CONTRIBUTING.md](https://github.com/porthole-dev/pmaports/blob/taimen-bringup/.github/CONTRIBUTING.md).
Changes to this repository's documentation and keys follow the same rules.

Human-written and AI-assisted contributions are both welcome.

- **Sign off every commit** (`git commit -s`). `Signed-off-by:` is your
  [Developer Certificate of Origin](https://developercertificate.org/). Only a
  person can give it, never an AI tool.
- **Disclose AI assistance.** If an AI tool helped write a change, add an
  `Assisted-by:` trailer naming the tool (for example `Assisted-by: Claude`),
  before your sign-off. See [AI.md](AI.md). Never list an AI tool as
  `Co-authored-by:` or in `Signed-off-by:`.
- Report a broken package here, not to postmarketOS or Alpine.
